PERSONAL MINI-TOOLKIT PROJECT PLAN

PROJECT TITLE: Personal Mini-Toolkit

1. SELECTED TOOLS AND DESCRIPTIONS

Tool 1: Simple Calculator
This tool allows users to perform addition, subtraction, multiplication and division using two numbers.

Tool 2: To-Do List Manager
This tool allows users to add new tasks, view their tasks and remove completed tasks.

Tool 3: Number Guessing Game
This tool challenges users to guess a secret number and provides hints until they find the correct answer.

Tool 4: Name Formatter
This tool allows users to enter their names and displays them in uppercase, lowercase and title case.

4. PROJECT GOAL

The goal of this project is to develop a simple,
 interactive and user-friendly Python toolkit that provides useful tools through a menu-driven program.
  The program will continue running until the user chooses to quit.
